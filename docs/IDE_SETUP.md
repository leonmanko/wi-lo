# Configuration IDE - WI-LO 
 
## VS Code 
 
1. Ouvrir le dossier wi-lo dans VS Code 
2. Installer les extensions recommandees (popup en bas a droite) 
3. Verifier que Prettier est le formateur par defaut 
4. Verifier que ESLint affiche les erreurs 
 
## Extensions obligatoires 
 
- ESLint 
- Prettier 
- Docker 
- GitHub Actions
